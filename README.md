Исследование топологии и мер центральности в социальной сети ВКонтакте на графе из **4 831 узла**. Проект реализует автоматический сбор окружения (1-й и 2-й круг контактов), расчет мер посредничества, близости и собственного вектора, а также визуализацию ключевых кластеров и мостов взаимодействия.

---

## 📌 Постановка задачи
1. Собрать данные о друзьях (1-й круг) и друзьях друзей (2-й круг) для участников студенческой группы через VK API.
2. Построить математический граф социальных связей с помощью библиотеки `NetworkX`.
3. Рассчитать ключевые метрики центральности:
   - **Центральность по посредничеству** (*Betweenness Centrality*);
   - **Центральность по близости** (*Closeness Centrality*);
   - **Центральность собственного вектора** (*Eigenvector Centrality*).
4. Провести топологический анализ роли каждого студента в структуре общей сети.

## 📐 Теоретическая база и математический аппарат

### 1. Посредничество (Betweenness Centrality)
Определяет долю кратчайших геодезических путей в сети, проходящих через узел:
$$C_B(v) = \sum_{s \ne v \ne t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$
* **Интерпретация:** Сайын выступает критической точкой связности сети (*Single Point of Failure*): через него проходит **71.1%** всех информационных транзитов графа.

### 2. Близость (Closeness Centrality)
Показывает скорость распространения информации от вершины до произвольного пользователя сети:
$$C_C(v) = \frac{N - 1}{\sum_{u \ne v} d(v, u)}$$
* **Интерпретация:** Наименьшее среднее число рукопожатий до всех 4 800 пользователей имеет Сайын ($0.405$), в то время как Руслан ($0.265$) наиболее удален от совокупного массива связей.

### 3. Собственный вектор (Eigenvector Centrality)
Оценивает статусность связей по принципу спектрального анализа матрицы смежности $A$:
$$A x = \lambda x \quad \Longleftrightarrow \quad \lambda x_v = \sum_{t \in M(v)} x_t$$
* **Интерпретация:** У Руслана 108 контактов, но $C_E \approx 0.004$, так как его окружение изолировано от внешних хабов. У Дмитрия при 40 контактах $C_E = 0.023$ (в 5 раз выше), поскольку его связи ведут напрямую к центральным фигурам выборки.

## 💾 Снимок сети (кэш данных VK)

Скрипт умеет сохранять всё собранное из VK в файл `vk_network_snapshot.json`, чтобы
**не обращаться к API повторно**. Это важно по двум причинам:

1. Сбор и расчёт метрик на графе из ~18 000 узлов занимает десятки минут;
2. Токен VK привязан к IP-адресу, и при его смене API начинает отвечать
   `error 5: access_token was given to another ip address`.

Снимок хранит не только рёбра графа, но и **исходные списки друзей** 1-го и 2-го круга.
Благодаря этому можно менять правила связывания и пересобирать граф, не опрашивая VK заново.

### Три режима работы

```bash
# 1. Первый запуск или обновление данных: идём в VK и сохраняем снимок
python vk_network_centrality_analysis.py --input students.txt --token "ТОКЕН" --update

# 2. Обычный запуск: работаем из снимка, VK не опрашивается
python vk_network_centrality_analysis.py

# 3. Пересборка графа из снимка по новым правилам (без VK)
python vk_network_centrality_analysis.py --force-rebuild
```

### Когда нужно обновлять снимок

| Ситуация | Команда |
| :--- | :--- |
| Кто-то из группы добавил нового друга | `--update` |
| Добавился новый одногруппник в `students.txt` | `--update` |
| Хотите поменять цвета/размер/дистанцию графа | обычный запуск |
| Хотите изменить правила связывания (`max_fof_clique`) | `--force-rebuild` |

Дополнительные параметры:

- `--snapshot FILE` — путь к файлу снимка (по умолчанию `vk_network_snapshot.json`);
- `--no-fof` — при обновлении собрать только 1-й круг, без друзей друзей.

> ⚠️ Снимок — это **статические данные на момент сбора**. Если между запусками прошло
> много времени, дружбы в VK могли измениться. Для актуальности запускайте `--update`.

## 🚀 Воспроизведение и запуск

### 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/Shadow-Comrade/vk-network-centrality.git
cd vk-network-centrality
pip install -r requirements.txt
```

### 2. Запуск анализа
```bash
# Полный цикл: собрать данные из VK, сохранить снимок, посчитать метрики и построить граф
python vk_network_centrality_analysis.py --input students.txt --token "ВАШ_VK_TOKEN" --update

# Повторный запуск из снимка (VK не опрашивается)
python vk_network_centrality_analysis.py

# Демонстрационный режим (без токена на синтетических данных):
python vk_network_centrality_analysis.py --demo
```

### 3. Настройка визуализации
```bash
python vk_network_centrality_analysis.py --figsize 50 --dpi 300 --spacing 3.2
```
